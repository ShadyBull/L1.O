# L1.O
An open-source Mouse, that can be 3D printet and for advanced people reshaped.

This is our study-project for the modul "Objekt und Entwurf" (object creation) - this took us almost 3 months at this point and have more ideas for the future.

![image](https://github.com/user-attachments/assets/486bb640-9a2f-4a9f-bc48-023c0e325c87)

![image](https://github.com/user-attachments/assets/06453eb4-1cf6-4416-b9c2-906f6aaa9c13)

You will find the complete mouse as "L1.O".stl, .f3d, .3mf and .obj files and the pieces in a folder as .stl files.

The Bot piece is constructed for a Logitech M-BZ96C Mouse board (MOMBASA06)



The Files are free to use, also the editing of the files. 
Don't use the Files and the remixed Files for commercial use.

Have fun with L1.O
