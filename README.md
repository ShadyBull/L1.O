# L1.O
An open-source mouse that can be 3D printed and, for advanced users, reshaped.

This is our study project for the module "Objekt und Entwurf" (object creation). It took us almost 3 months to complete, and we have more ideas for the future.

![image](https://github.com/user-attachments/assets/486bb640-9a2f-4a9f-bc48-023c0e325c87)

![image](https://github.com/user-attachments/assets/06453eb4-1cf6-4416-b9c2-906f6aaa9c13)

You will find the complete mouse as "L1.O" in .stl, .f3d, .3mf, and .obj files. The individual pieces are also available in a folder as .stl files.

The bottom piece is designed for a Logitech M-BZ96C mouse board (MOMBASA06) - check the pictures below.
